# Burkholderia-ARG-Analysis
Genomic profiling and Antibiotic Resistance Gene (ARG) identification in Burkholderia pseudomallei using CARD/RGI tools.

Project Summary:
Project Objective: Detection of antimicrobial resistance genes (ARGs) in bacterial genome data using RGI (Resistance Gene Identifier) and the CARD database.
Tools Used: Python, Pandas, Matplotlib, Seaborn, RGI (Resistance Gene Identifier).
Outputs: Visualizations of drug classes and resistance mechanisms.
